# ok-script 任务开发指南

> 适用项目: ok-raw (基于 ok-script 框架 `ok/`)
> 框架版本: 本仓库 `.venv/Lib/site-packages/ok/` 内置版本
> 面向读者: 需要从 0 编写 EVE 自动化任务的开发者

---

## 1. 任务类型与注册

框架中共有 **三类任务**, 全部在 `src/config.py` 中注册:

| 类型 | 注册键 | 触发方式 | 典型用途 |
|---|---|---|---|
| 一次性任务 | `onetime_tasks` | 用户在 GUI 点击任务卡片 | 登录游戏、诊断、单次流程 |
| 触发任务 | `trigger_tasks` | 框架按 `schedule` 周期轮询 `should_trigger()`, 返回 True 时自动执行 `run()` | 挂机刷怪、定时巡检、守护任务 |
| 自定义任务 | `custom_tasks: True` | 用户在 GUI 的"自定义任务"页创建脚本 (`ok_tasks/` 目录) | 快速试验、用户自建脚本 |

```python
# src/config.py
config = {
    'custom_tasks': True,          # 允许 GUI 创建/编辑自定义任务脚本
    'onetime_tasks': [             # 点击触发, 跑一次 run() 就结束
        ["src.tasks.MyOneTimeTask", "MyOneTimeTask"],   # [模块路径, 类名]
        ["ok", "DiagnosisTask"],
    ],
    'trigger_tasks': [             # 常驻任务, 由框架轮询自动触发
        ["src.tasks.MyTriggerTask", "MyTriggerTask"],
    ],
    ...
}
```

**注册格式永远是 `[模块路径, 类名]`**, 第二个参数是类名而非显示名; GUI 上显示的名字由任务内部的 `self.name` 决定。

## 2. 从 0 编写一个任务

### 2.1 目录约定

```
ok-raw/
├── src/
│   ├── config.py            # 任务注册
│   └── tasks/
│       ├── MyBaseTask.py    # 项目公共基类(可选, 建议有)
│       └── MyTask.py        # 具体任务
├── assets/
│   └── coco_annotations.json  # 模板匹配标注(COCO 格式)
└── configs/
    └── MyTask.json          # 任务配置自动持久化(无需手写)
```

### 2.2 最小可用任务

```python
from ok import BaseTask

class MyTask(BaseTask):

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.name = "我的任务"                # GUI 显示名
        self.description = "任务功能描述"
        self.default_config.update({          # 任务参数(见第 3 节)
            'Enabled': True,
        })

    def run(self):
        # 任务主体逻辑
        self.log_info('任务执行', notify=True)
```

### 2.3 项目基类

项目已有 `src/tasks/MyBaseTask.py` 继承 `BaseTask`, 新任务建议继承 `MyBaseTask`, 便于沉淀 EVE 通用逻辑(窗口绑定、场景判断等)。

```python
from src.tasks.MyBaseTask import MyBaseTask

class MyEveTask(MyBaseTask):
    ...
```

## 3. 任务 UI 与参数

任务的参数面板完全由三个字典驱动, **修改后 GUI 自动生成对应控件并持久化到 `configs/<类名>.json`**:

```python
self.default_config.update({...})        # 1. 参数名 -> 默认值
self.config_description.update({...})    # 2. 参数名 -> 描述文案(GUI 悬浮提示/翻译 key)
self.config_type.update({...})           # 3. 参数名 -> 控件类型(缺省按默认值类型自动推断)
```

### 3.1 控件类型速查 (`config_type`)

| type | 默认值形态 | 说明 |
|---|---|---|
| (自动/bool) | `True/False` | 开关 Switch |
| (自动/int, float) | `1` / `1.1` | 数字输入框 |
| (自动/str) | `"abc"` | 单行文本框 |
| `text_edit` | 多行字符串 | 多行文本框 |
| `drop_down` | `"选项1"` + `options: [...]` | 下拉框; 支持 `sub_configs` 按选中值联动显示其他参数 |
| `drop_down` + `options_available` | 列表 + `allow_duplication` | 可自由增删条目的下拉框 |
| `multi_selection` | 列表 + `options: [...]` | 多选 |
| `file_selector` | `selector_type: "folder"/"file"` | 文件/文件夹选择器, 可加 `dialog_title`/`filter` |
| `button` | `text` + `callback` | 按钮; 多按钮用 `buttons: [{text, callback}, ...]` |
| `global` | `{}` | 引用全局配置(见 3.2) |

### 3.2 全局配置 (跨任务共享)

```python
# src/config.py — 定义全局配置项
key_config_option = ConfigOption('Game Hotkey Config', {
    'Echo Key': 'q',
}, description='In Game Hotkey for Skills')
config = {'global_configs': [key_config_option], ...}

# 任务内读取
self.get_global_config('Game Hotkey Config')   # -> dict
# 任务参数里挂 GUI 引用
self.config_type.update({'Game Hotkey Config': {'type': 'global'}})
```

### 3.3 参数校验

```python
def validate_config(self, key, value):
    """返回字符串=校验失败的错误提示; 返回 None=通过"""
    if key == 'Interval' and value < 1:
        return '间隔不能小于 1 秒'
```

### 3.4 信息面板 (任务卡片上的统计显示)

```python
self.info_set('击杀数', 12)          # 设置某项显示值
self.info_incr('击杀数')             # 自增
self.info_add('击杀数', 5)           # 加 N
self.info_add_to_list('日志', item)  # 追加列表项
self.info_clear()                    # 清空
```

## 4. 生命周期与运行控制

### 4.1 关键方法

| 方法 | 调用时机 |
|---|---|
| `__init__` | 框架启动加载任务时 (仅一次) |
| `post_init()` / `after_init()` | 任务初始化后 (OCR 等重资源在 post_init 做延迟加载) |
| `run()` | 任务执行主体 |
| `should_trigger()` | 仅 trigger 任务: 返回 True 才会执行 run |
| `enable()` / `disable()` | 用户在 GUI 开/关任务 |
| `pause()` / `unpause()` | 暂停/恢复 (F9 全局暂停同路径) |
| `on_create()` / `on_destroy()` | 任务创建/销毁钩子 |

### 4.2 两类任务的 run 语义

- **onetime 任务**: 点击卡片 → `executor.enqueue_onetime_task` → `run()` 执行一次 → 结束。
- **trigger 任务**: executor 周期调用 `should_trigger()`(默认实现返回 `self.enabled and 条件`) → True 时执行 `run()` → 执行完继续轮询。用 `self.next_schedule` / `self.schedule` 控制下次触发间隔。

### 4.3 启动链 (点 F9 / 点"开始"后发生什么)

```
StartController._do_start
  → device_manager.do_refresh()            # 刷新设备列表
  → start_device()                          # 设备未连接时 execute(exe) 拉起游戏
  → _wait_until_device_ready()              # 轮询等待窗口就绪
  → _mark_task_enabled(task)                # 启用本次要跑的任务
  → executor.start()                        # 开始执行任务
```

相关配置: `config['start_timeout']`; `windows.start_exe` 控制是否自动拉起游戏; `calculate_pc_exe_path` 强制启动路径。

### 4.4 一次性任务的"跑完即退"

```python
task.exit_after_task = True   # 任务跑完自动退出程序(配合挂机收尾)
```

## 5. 核心 API 速查

### 5.1 截图与画面

```python
self.frame                      # 当前帧 (numpy BGR), 框架自动按 supported_resolution 缩放
self.width / self.height        # 逻辑分辨率
self.screenshot(name='debug')   # 保存截图到 screenshots/ 目录
self.next_frame()               # 阻塞等待下一帧
```

### 5.2 模板匹配 (找图, 基于 COCO 标注)

```python
self.find_one('login_button')                       # -> Box 或 None (最优匹配)
self.find_feature('login_button')                   # -> Box 列表 (全部匹配)
self.feature_exists('login_button')                 # -> bool
self.get_box_by_name('login_button')                # 带缓存的 box
self.wait_feature('login_button', time_out=10)      # 等待出现
self.wait_click_feature('login_button')             # 等待出现并点击
```

- `horizontal_variance` / `vertical_variance`: 允许的偏移范围(默认取 config.py `template_matching` 的 0.002)
- `threshold`: 匹配阈值(默认 0.8)
- 标注流程: debug 模式运行 → GUI "标注" 页框选特征 → 保存到 `assets/coco_annotations.json` → 特征名即 API 的 feature_name

### 5.3 OCR 文字识别

```python
self.ocr(box='bottom_right', match='商城')          # 指定区域+匹配文本
self.ocr(0.5, 0.5, 1, 1, match=re.compile('招'))    # 比例坐标 box
self.wait_ocr(match='开始游戏', time_out=10)         # 等待文字出现
self.wait_click_ocr(match='确认')                    # 等待并点击
```

- `box` 支持字符串(预定义区域)/`Box` 对象/四个比例坐标; **务必缩小 box 提速**
- `match` 支持字符串或正则; 返回 `Box` 列表(带 text 属性)
- OCR 库在 config.py `ocr` 段配置(onnxocr + openvino)

### 5.4 等待与条件

```python
self.sleep(2)                                        # 任务级 sleep(可被暂停打断)
self.wait_until(lambda: self.find_one('xx') is not None, time_out=10)
self.wait_click_box(lambda: self.box_of_screen(0.4,0.8,0.6,1.0))
```

### 5.5 输入模拟

```python
self.click(x, y)                    # 点击(支持 Box/Box 列表)
self.click_relative(0.5, 0.9)       # 比例坐标点击
self.click_box(box)                 # 点 box 中心
self.right_click(x, y) / self.middle_click(...)
self.send_key('q')                  # 按键
self.input_text('hello')            # 输入文本
self.swipe(fx, fy, tx, ty, duration=0.5)
self.scroll(x, y, count)
```

交互后端由 config.py `windows.interaction` 决定, 优先级即列表顺序:
`Pynput`(仅前台) → `PostMessage`(可后台) → `Genshin`/`PyDirect`/`ForegroundPostMessage`。

### 5.6 日志与通知

```python
self.log_info('消息')                        # 日志面板
self.log_info('消息', notify=True)           # 同时弹系统通知
self.log_warning / self.log_error(msg, exception=e)
self.notification('标题', title='自定义标题', error=False, tray=True)
```

### 5.7 窗口与设备绑定

```python
self.hwnd                          # 当前绑定窗口句柄
self.ensure_in_front()             # 确保窗口在前台
# 编程切换绑定窗口(与 GUI 手选同路径):
og.device_manager.set_preferred_device(f'pc_{hwnd}')
# 等截图线程跟随到目标窗口:
self.wait_until(lambda: self.hwnd == 目标hwnd)
```

## 6. 调试与运行

### 6.1 启动方式

```bash
# 开发调试(GUI 带 debug 标记, 启用热重载/标注功能)
.venv/Scripts/python.exe -X utf8 ok-raw/main_debug.py

# 正式运行
.venv/Scripts/python.exe -X utf8 ok-raw/main.py
```

- 入口已强制 `os.chdir` 到脚本目录, 从任何 cwd 启动配置都落在 `ok-raw/configs`
- `PYAPPIFY_PYTHON_TEST=1` 已内置, 避免开发环境 pyappify 更新检查崩溃

### 6.2 调试手段

| 手段 | 用法 |
|---|---|
| 实时日志 | GUI 日志面板 / `ok-raw/logs/ok-script.log` |
| 截图留档 | `self.screenshot('名字')` → `screenshots/` |
| 框选标注 | debug 模式 GUI 标注页, 产出 `assets/coco_annotations.json` |
| 自定义任务热重载 | `custom_tasks: True` 时修改 `ok_tasks/` 脚本自动重载 |
| 单任务命令行 | F9 前在 GUI 任务页只勾选目标任务 |

### 6.3 常见坑

1. **run() 内不要自己写 while True 大循环** — trigger 任务靠框架轮询, onetime 任务跑一次; 需要循环时用 `wait_until` + `self.sleep`
2. **OCR/找图务必传 box** — 全屏 OCR 单次可达数百 ms, 缩小区域可快 10 倍
3. **窗口最小化会黑屏** — 所有截图 API 均失效, 框架会自动暂停; 后台(被遮挡)用 WGC 正常
4. **中文编码** — 入口已强制 UTF-8, 但自建脚本含中文注释路径时仍建议 UTF-8 保存
5. **配置改动即时落盘** — `configs/<类名>.json` 每次改动自动保存, 别手工编辑正在运行的配置

## 7. 完整示例: EVE 自动登录骨架 (onetime 任务)

```python
import re
from qfluentwidgets import FluentIcon
from src.tasks.MyBaseTask import MyBaseTask
from ok import og


class EveLoginTask(MyBaseTask):

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.name = "EVE 自动登录"
        self.description = "拉起启动器并完成账号登录"
        self.icon = FluentIcon.CONNECT
        self.default_config.update({
            '等待超时(秒)': 30,
            '角色名': '',
        })
        self.config_description.update({
            '等待超时(秒)': '每一步等待的最长时间',
            '角色名': '多角色时用于确认进入的角色',
        })

    def run(self):
        timeout = self.config['等待超时(秒)']

        # 1. 确保游戏窗口就绪(F9 启动链已自动拉起启动器)
        if not self.wait_until(lambda: self.hwnd, time_out=timeout):
            self.log_error('游戏窗口未就绪', notify=True)
            return

        # 2. 等待并点击登录按钮 (特征名来自 coco_annotations.json 标注)
        if not self.wait_click_feature('login_button', time_out=timeout):
            self.log_warning('未找到登录按钮, 可能已登录', notify=True)
            return

        # 3. 等待进入角色选择界面 (OCR)
        entered = self.wait_ocr(match=re.compile('角色选择|舰船库'), time_out=timeout)
        if entered:
            self.info_set('状态', '已进入角色界面')
            self.log_info('登录成功', notify=True)
        else:
            self.info_set('状态', '等待超时')
```

注册到 `src/config.py`:

```python
'onetime_tasks': [
    ["src.tasks.EveLoginTask", "EveLoginTask"],
],
```
